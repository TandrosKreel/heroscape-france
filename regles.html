Règles Heroscape

Une page de consultation claire, organisée par thèmes. Les documents PDF peuvent être ajoutés dans le dossier documents/ puis liés ici.

1. Le principe du jeu

Heroscape est un jeu de combat tactique sur terrain modulaire. Chaque joueur compose une armée à partir de cartes d'armée, place ses figurines dans sa zone de départ et utilise les marqueurs d'ordre pour déterminer les activations.

2. Déroulement d'un tour

Les joueurs placent secrètement leurs marqueurs d'ordre, puis les résolvent dans l'ordre 1, 2, 3 et enfin le marqueur X selon les effets de cartes. Les déplacements, attaques, pouvoirs spéciaux et jets de dés sont ensuite résolus selon les règles applicables.

3. Terrain et hauteur

Le terrain modulaire détermine les déplacements et peut modifier les possibilités d'attaque et de défense. Les lignes de vue et les espaces clairement visibles sont déterminants pour les attaques à distance et certains pouvoirs.

4. Cartes d'armée

Une carte d'armée présente notamment les caractéristiques de l'unité, son coût en points et ses pouvoirs spéciaux. La page Cartes d'armée permet de parcourir le catalogue local.
